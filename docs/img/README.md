# Pictures

Every picture here was taken from METEOR V1 1.0.0 with made-up content: a pretend agent session in a folder called `sample-app`, pretend reminders and notes. Each shows only the product's own window, at the device scale, on a plain dark ground.

| File | What it shows |
| --- | --- |
| `island-home.png` | The open island on Home: the mascot, a Claude Code session at work and a Codex session beside it. |
| `island-dashboard.png` | The Dashboard: a card for the agents, a card for the next event, and the processor and memory chip. |
| `island-strip.png` | The small island at rest: the mascot and a running timer. |
| `island-permission.png` | A permission card: the command an agent wants to run, with Allow and Deny. |
| `island-question.png` | A question from an agent, with its answers as buttons. |
| `island-finished.png` | The card an agent leaves when it has finished, with its summary as formatted text. |
| `island-timer.png` | The Timer section with a countdown running. |
| `island-reminders.png` | The Reminders section with three reminders. |
| `island-shelf.png` | The Shelf holding a note and a link. |
| `capture-editor.png` | The capture editor with a picture open and its drawing tools. |
| `settings-features.png` | Settings, the Features page: one switch for each feature. |
| `settings-island.png` | Settings, the Island page: how the island opens, stays and closes. |
| `settings-mascot.png` | Settings, the Mascot page. |
| `settings-welcome.png` | The welcome page of the first start: three bundles of features to begin with. |
